# Changelog

## 0.2.23 - 2026-10-29

- Do not flag every comma before *och* or every em dash as an error; punctuation depends on context.
- Accept three dots as a valid ellipsis alongside the single-character form.
- Correct the Swedish number-range guidance to allow tankstreck and spaced hyphens.
- Document the reviewed scope and limits of automated Swedish writing checks.

## 0.2.22 - 2026-10-26

- Warn about repeated consonants in Swedish compounds and suggest corrections for known misspellings.

## 0.2.21 - 2026-10-25

- Package the current Swedish review toolkit for PyPI.
- Publish releases through GitHub Actions Trusted Publishing.
